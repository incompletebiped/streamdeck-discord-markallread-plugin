The key focuses the Discord desktop app and walks the server list with Discord's own shortcuts: Shift+Esc marks the current server read, and Ctrl+Alt+Down moves to the next server. Direct messages are skipped. Expand server folders first, and set the server count to at least the number of icons in your list. Some graphics drivers use Ctrl+Alt+Arrow to rotate the screen, so turn that hotkey off before you check the box above. Leave the keyboard alone while the key runs. This plugin does not log in to Discord.
