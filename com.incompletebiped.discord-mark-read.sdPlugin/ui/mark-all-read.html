The key presses the Read All button from Vencord's Read All Notifications Button plugin. Enable that plugin in Vesktop, then reload Vesktop once with Ctrl+R. After that, one press marks every unread server. It does not walk the server list, send keyboard shortcuts, or log in. Official Discord works the same way when that Vencord plugin is enabled there. If the key says Reload, reload Vesktop. If it says Enable, turn the Read All plugin on. If it says Open app, open Vesktop first.
